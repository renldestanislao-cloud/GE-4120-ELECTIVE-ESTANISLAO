# Activity 5: Exploring and Improving AI Prompts

## Short Description
This activity involved creating an original AI prompt, improving it with the help of an LLM, and comparing the outputs to understand how prompt quality affects AI-generated responses.

## What Have I Learned?
I learned that the quality of an AI-generated response depends greatly on how clear and specific the prompt is. I also discovered that providing context, instructions, and expected output formats can produce more accurate and useful results. One challenge was identifying the differences between the original and improved outputs, which I addressed by comparing their clarity, details, and relevance. In the future, I can apply effective prompt-writing techniques to improve my productivity and make better use of AI tools.
