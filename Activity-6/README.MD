# Activity 6: Making a Website

## Short Description
This activity involved choosing a website concept and using an AI-powered or other website-building tool to create a one-page website, documenting the process through screenshots and a reflection.

## What Have I Learned?
I learned how to turn an idea into a functional website using website-building tools. I also gained an understanding of how prompts and clear instructions can influence the appearance and content of a website. One challenge I encountered was making sure the generated website matched my original concept and included the necessary information. I addressed this by refining my prompts and making adjustments to the website. In the future, I can use these skills to create personal portfolios, business websites, or platforms for advocacy projects.
