# Activity 3: Creating an Infographic and Project Documentation Report

## Short Description
This activity involved creating a one-page infographic about a real-world problem and preparing a project documentation report proposing a technology-based solution.

## What Have I Learned?
I learned how to simplify complex information and present it through visuals, statistics, and concise explanations. I also developed my skills in researching problems and proposing practical technology-based solutions. One challenge I encountered was selecting the most relevant information while keeping the infographic visually appealing and understandable. I addressed this by organizing the content and focusing on the most important details. I can apply these skills in future academic projects and professional presentations.
