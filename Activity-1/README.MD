# Activity 1: Principles of Visual Communication and Presentation Design

## Short Description
This activity focused on understanding the importance of visual communication and how effective presentation design helps capture attention, organize information, and deliver messages clearly.

## What Have I Learned?
I learned that good presentation design is not just about making slides attractive but also about making information easy to understand. I became more aware of the importance of proper layouts, font sizes, colors, and visual hierarchy. One challenge I faced was identifying what information should be emphasized, which I addressed by organizing the content and avoiding unnecessary details. In the future, I can apply these principles when creating academic presentations and other visual materials.
