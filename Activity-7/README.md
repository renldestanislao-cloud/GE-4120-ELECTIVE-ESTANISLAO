# Activity 7: Creating a Résumé Using AI

## Short Description
This activity focused on using AI tools to generate and improve a professional résumé by providing personal information, educational background, skills, and relevant experiences.

## What Have I Learned?
I learned how AI can help organize information and create a professional-looking résumé suitable for job applications. I also realized that providing accurate and specific details is important to ensure that the generated résumé properly represents my qualifications. One challenge I faced was making sure the AI-generated content was relevant, concise, and properly formatted. I addressed this by reviewing the output, correcting details, and refining the instructions to achieve a better result. In the future, I can use AI as a tool to improve my professional documents while ensuring that the information remains accurate and authentic.
